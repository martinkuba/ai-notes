# AI writes the code now. What's left for software engineers?

**Original source:** [AI writes the code now. What's left for software engineers?](https://sfstandard.com/2026/02/19/ai-writes-code-now-s-left-software-engineers/)
**Author:** Rya Jetha

## Summary

This article documents the growing anxiety among software engineers in San Francisco as AI coding tools, particularly Anthropic's Claude Code and its Opus 4.6 model, rapidly approach and in some cases surpass human-level coding ability. The piece centers on a pivotal moment many engineers call "Claude Christmas" -- the November 2025 release of a new Claude Code model that could autonomously build features, run tests, fix bugs, and check its own work with minimal human guidance. Engineers report that the ratio of designing to writing code has inverted: what was once 20% design and 80% coding has shifted to a world where engineers rarely write code at all.

The labor market impact is already visible. Hiring of new graduates at the 15 largest U.S. tech companies has fallen 55% since 2019, and undergraduate computer science enrollment across the UC system has declined for the first time since the dot-com bust. Engineers at Anthropic and OpenAI report that AI writes 100% of their code. Several engineers interviewed describe feelings of grief, existential unease, and fear of obsolescence, with some contemplating entirely different careers. The concept of a "permanent underclass" -- people once assured of well-paying tech jobs being locked out of economic mobility -- has become common parlance in Silicon Valley.

The article presents both optimistic and pessimistic framings. Optimists invoke the compiler analogy: each wave of automation in software historically created more jobs by making development cheaper and expanding the market. Pessimists counter with the tractor analogy, arguing that tractors did not create more farming jobs but emptied entire regions. Labor economist Enrico Moretti suggests San Francisco may be uniquely positioned to benefit, as AI industry growth could offset the displacement of traditional software roles. UC Berkeley professor James O'Brien advocates for universal basic income as a hedge against worst-case outcomes, warning that the choices made now will determine whether the future resembles "Star Trek" or "The Hunger Games."

## Main Ideas

- The release of Claude Code in November 2025 ("Claude Christmas") marked a step change in AI coding capability, enabling autonomous project building with minimal human oversight.
- Engineers increasingly describe themselves as proxies to AI coding tools rather than active coders, with some understanding only half the code they produce.
- The labor market is already contracting: new grad tech hiring is down 55% since 2019, CS enrollment is declining, and AI-driven layoffs are occurring at major companies.
- Boris Cherny, creator of Claude Code, predicts the title "software engineer" will be replaced by "builder" or "product manager."
- Historical analogies are contested: the compiler analogy suggests AI will expand the software market and create jobs, while the tractor analogy warns of massive displacement.
- San Francisco may be an exception to net job loss trends due to its concentration of AI research and development activity.
- Experts including Anthropic's CEO warn that AI could eliminate half of entry-level white-collar jobs within one to five years, with some predicting overall unemployment of 20-30%.

## Key Quotes

- "If suddenly we have a machine that's able to do all the things that society thought you were valuable for, that's very existentially upsetting."
- "Today coding is practically solved. We're going to start to see the title of software engineer go away. It's just going to be 'builder' or 'product manager.'"
- "Both stories start with the machines doing all the work."
