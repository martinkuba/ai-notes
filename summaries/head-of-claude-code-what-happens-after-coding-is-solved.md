# Head of Claude Code: What happens after coding is solved | Boris Cherny

**Original source:** [Head of Claude Code: What happens after coding is solved | Boris Cherny](https://www.youtube.com/watch?v=We7BZVKbCVw&t=1s)
**Author:** Lenny's Podcast

## Summary

Boris Cherny, head of Claude Code at Anthropic, discusses the trajectory of AI coding tools and what comes next now that coding is, in his view, largely solved. He shares that 100% of his code has been written by Claude Code since November 2025, shipping 10-30 pull requests daily without editing a single line by hand. A Semi Analysis report found that 4% of all GitHub commits are authored by Claude Code, with predictions it will reach a fifth by year's end -- and private repository usage is likely much higher. Anthropic's engineering productivity has increased 200% per engineer since introducing Claude Code internally.

Cherny traces Claude Code's origin story from a solo hack project that initially received just two internal likes to becoming a multi-billion dollar product. Key product insights include building for the model six months out rather than today, embracing "latent demand" by observing how users repurpose tools in unexpected ways (which led to co-work for non-technical tasks), and keeping minimal scaffolding around the model rather than boxing it in with rigid workflows. He advocates giving engineers unlimited tokens to experiment, underfunding teams slightly to encourage AI adoption, and following the "bitter lesson" of always betting on the more general model.

Looking ahead, Cherny sees Claude Code beginning to autonomously identify bugs and propose features by analyzing feedback channels, effectively evolving from a coding tool into a coworker. He predicts the title "software engineer" will start to disappear, replaced by "builder," and that everyone will become a product manager who codes. He draws a historical analogy to the printing press, arguing that programming becoming universally accessible could unlock transformations as profound as the Renaissance. Anthropic's three-layer safety approach -- mechanistic interpretability, lab evaluations, and real-world deployment observation -- underpins their willingness to release products early to study alignment in practice.
