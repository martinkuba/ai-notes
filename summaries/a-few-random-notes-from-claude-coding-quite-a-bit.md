# A few random notes from claude coding quite a bit...

**Original source:** [A few random notes from claude coding quite a bit...](https://x.com/karpathy/status/2015883857489522876/?rw_tt_thread=True)
**Author:** Andrej Karpathy

## Summary

Andrej Karpathy shares observations from rapidly shifting his coding workflow to roughly 80% AI agent coding and 20% manual edits, calling it the biggest change to his programming workflow in two decades. He describes how LLM coding agents (particularly Claude) crossed a threshold of coherence around December 2025, causing a phase shift in software engineering. Despite this, he cautions against both the "no need for IDEs" and "agent swarm" hype, noting that models still make subtle conceptual errors -- not simple syntax mistakes, but the kind a hasty junior developer would make, such as wrong assumptions made without checking, failure to surface inconsistencies or tradeoffs, sycophantic agreement, and tendency to overcomplicate code with bloated abstractions.

Karpathy identifies several key dynamics of working with AI coding agents. Tenacity stands out: agents relentlessly work through problems where a human would give up, revealing that stamina is a core bottleneck in knowledge work. The "speedup" framing is misleading -- the primary effect is expansion, enabling projects that would not have been worth building and work in areas outside one's expertise. He advocates a declarative rather than imperative approach: give agents success criteria and let them loop, write tests first and have agents pass them, put agents in the loop with browser MCP. Programming has become more fun because drudgery is removed and creative work remains, though he acknowledges some engineers who primarily enjoyed coding (rather than building) may feel differently. He also notes early signs of skill atrophy in manual code writing, and predicts 2026 will bring a "slopacolypse" of AI-generated low-quality content across GitHub, Substack, arXiv, and social media.

Among the open questions he raises: whether the productivity gap between mean and top engineers will widen dramatically, whether generalists will outperform specialists when armed with LLMs, and what LLM coding will ultimately feel like -- StarCraft, Factorio, or playing music.

## Main Ideas

- Karpathy shifted from 80% manual coding to 80% agent coding in weeks, calling it the biggest workflow change in 20 years.
- AI coding agents crossed a "threshold of coherence" around December 2025, triggering a phase shift in software engineering.
- Agent errors are now subtle conceptual mistakes rather than syntax errors -- wrong assumptions, overcomplicated code, failure to push back.
- Agent tenacity is remarkable: they work through problems relentlessly, revealing stamina as a core bottleneck in human work.
- The real benefit is not speedup but expansion -- enabling projects and domains that were previously not worth the effort.
- A declarative approach (giving success criteria, writing tests first) yields more leverage from agents than imperative step-by-step instructions.
- Manual coding skill atrophy is already observable; generation and discrimination (writing vs. reading code) are different capabilities.

## Key Quotes

- "This is easily the biggest change to my basic coding workflow in ~2 decades of programming and it happened over the course of a few weeks."
- "Don't tell it what to do, give it success criteria and watch it go."
- "I didn't anticipate that with agents programming feels more fun because a lot of the fill in the blanks drudgery is removed and what remains is the creative part."
