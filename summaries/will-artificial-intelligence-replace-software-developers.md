# Will Artificial Intelligence Replace Software Developers?

**Original source:** [Will Artificial Intelligence Replace Software Developers?](https://www.stxnext.com/blog/will-artificial-intelligence-replace-developers/)
**Author:** STX Next

## Summary

This article from STX Next surveys the history and trajectory of AI in software development, examining whether AI will replace human programmers. It traces key milestones — Deep Blue beating Kasparov (1997), Watson winning Jeopardy (2011), AlphaGo defeating Lee Sedol (2016) — before turning to AI's growing ability to write code. Early experiments by Andrej Karpathy (2015) showed that a recurrent neural network trained on Linux source code could overnight generate syntactically plausible C code with functions, parameters, loops, correct indentation, and comments, though it didn't compile. Similar experiments with Python yielded code that defined classes, used boolean expressions, and created arrays, albeit with errors.

The article covers several AI coding tools: Microsoft/Cambridge's DeepCoder (which searches code databases to assemble working programs), Diffblue (AI-generated unit tests from Oxford spin-out), Visual Studio IntelliCode (context-aware code completion), and GitHub Copilot (which drew both praise and criticism from the Free Software Foundation over licensing concerns). It also discusses Andrej Karpathy's "Software 2.0" thesis — that developers will shift from writing code to curating datasets for machine learning systems.

The consensus from experts cited in the article is that AI won't replace developers in the near term but will automate tedious tasks while humans focus on complex, creative work. An Evans Data Corp survey found that 29% of 550 developers said their greatest career concern was being "replaced by artificial intelligence." The article concludes that software development is too complex for full AI automation — AI can't yet interpret business value, advise on feature prioritization, or handle the holistic design thinking that humans provide. Stephen Hawking's advice is cited: develop direct brain-computer connections so computers augment rather than oppose human intelligence.

## Main Ideas

- AI has achieved impressive milestones (chess, Jeopardy, Go) and is increasingly capable of generating code
- Early experiments showed AI could generate syntactically plausible code overnight but it wouldn't compile
- Tools like GitHub Copilot, IntelliCode, and Diffblue automate specific development tasks but don't replace developers
- Karpathy's "Software 2.0" thesis argues developers will shift from coding to curating data for ML systems
- 29% of surveyed developers cite AI replacement as their top career concern
- Expert consensus: AI will automate tedious tasks but can't replace human creativity, business judgment, and holistic design thinking
- Software development's inherent complexity makes full automation unlikely in the near term
