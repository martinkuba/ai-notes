# Code is Clay

**Original source:** [Code is Clay](https://campedersen.com/code-is-clay)
**Author:** campedersen.com

## Summary

This short essay draws a parallel between code and clay as creative mediums. The author, inspired by a ceramics class where they made a hypercube instead of the assigned mug, observes that both materials are malleable, responsive, and prone to breaking—and that the healthy response to breakage is to start over without attachment. Code, like clay, is "just text"—delete it, rewrite it, start fresh. The idea survives even when the implementation doesn't.

The essay frames AI-generated code as the "industrial revolution" of software. When the industrial revolution came for pottery, factories mass-produced cheap ceramics—but clay didn't disappear. Ceramics studios are everywhere now because the craft got more valuable once it wasn't necessary anymore. Choosing to make something by hand, when you don't have to, makes it mean something different. The author sees the same future for programming: production work and commodity code gets automated, but the craft remains—the weird ideas, the hypercubes, the things that don't fit templates.

The piece concludes optimistically: the author got into programming to build things, not to type boilerplate. If AI handles the mugs, they can focus on the hypercubes. The medium isn't going anywhere—it's just getting more interesting.

## Main Ideas

- Code and clay are both malleable creative mediums—neither should be treated as precious or sacred
- AI-generated code parallels the industrial revolution of pottery: commodity production gets automated, but the craft endures
- When making something by hand is no longer necessary, choosing to do so gives it new meaning
- The creative, non-formulaic aspects of programming ("the hypercubes") will remain human territory
- Programmers should embrace AI handling boilerplate to focus on genuinely creative work
