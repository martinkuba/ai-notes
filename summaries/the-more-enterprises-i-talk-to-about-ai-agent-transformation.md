# The more enterprises I talk to about AI agent transformation...

**Original source:** [The more enterprises I talk to about AI agent transformation...](https://x.com/levie/status/2043883641366032638/?rw_tt_thread=True)
**Author:** Aaron Levie

## Summary

Aaron Levie argues that enterprises implementing AI agents will need to create a new organizational role: the AI agent deployer and manager. This position would focus on identifying high-leverage workflows where agents can deliver 100x improvements in speed or scale, then architecting and managing the technical implementation. The role requires identifying which processes would benefit most from automation—such as lead processing, contract review, client onboarding, and knowledge base setup—and redesigning workflows to maximize agent effectiveness while determining optimal human-agent interaction points. The agent deployer must possess both technical capabilities (working with skills, MCPs, CLIs, and system integrations) and strong operational/business acumen. Rather than being centralized, these roles would likely exist distributed across teams, though potentially reporting into IT or central AI functions. Levie suggests this represents a significant career opportunity for technical talent interested in AI, and provides a clear path for engineers to remain relevant as automation expands.

## Main Ideas

- A new specialized role—AI agent deployer and manager—will become standard across enterprises
- These professionals identify workflows where agents can deliver exponential improvements (100x faster or more scalable)
- The position combines technical skills (system integration, MCP, CLI proficiency) with business process expertise and operational management
- Key responsibilities include workflow redesign, data flow mapping, managing agent context, defining human intervention points, and ongoing KPI tracking
- Roles may be distributed across teams rather than centralized, and can either be new hires or repositioned existing employees
- This represents a significant career opportunity for technical talent and engineers adapting to AI-driven transformation

## Key Quotes

"This person will need to figure out what are the highest leverage set of workflows on a team are (either existing or new ones) where agents can actually drive significantly more value for the team and company."

"This would also be a fantastic job for next gen hires who are leaning into AI, and are technical, to be able to go into. And for anyone concerned about engineers in the future, this will be an obvious area for these skills as well."
