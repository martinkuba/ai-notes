# Claude + Obsidian Got a Level Up

**Original source:** [Claude + Obsidian Got a Level Up](https://www.eleanorkonik.com/p/claude-obsidian-got-a-level-up?utm_campaign=post&utm_medium=web)
**Author:** Eleanor Konik

## Summary

Eleanor Konik, a non-programmer and Obsidian power user, describes how Claude Code has become a core part of her workflow after coding agents "turned a corner." Using the Terminal plugin for Obsidian, she runs Claude Code directly within her knowledge base. The AI processed her entire 15-million-word vault overnight, creating an index file, cleaning up files she hadn't touched, fixing RSS encoding glitches, updating outdated metadata, and committing changes via git pull requests—all without risking data destruction. She also had Claude build her a custom Obsidian plugin and a Telegram bot for quick capture, both working after minimal debugging.

The key insight is that Claude Code's value for non-programmers isn't about doing things faster—it's about doing them "with less attention." Tasks that required active clicking and searching now run in the background and actually get completed. Konik compares this to learning to delegate: just as she delegates household tasks to her children and babysitter, she can now delegate vault maintenance and plugin development to Claude. She emphasizes that building the habit of clear, precise communication (learned from explaining things to teenagers and children) directly translates to effective LLM prompting.

Konik provides practical tips: use git and commit after every change for version control; put the vault in a top-level folder to access other repositories with the same permissions; treat commands as modular functions; tell Claude to document corrections in skill files; and explicitly instruct Claude to keep hitting APIs with different queries to ensure thoroughness. She sees this as a "phase change" in AI usefulness since Christmas 2025, moving from occasional utility to a central workflow tool that shifts personal knowledge management from "managing" notes to actually "utilizing" them.

## Main Ideas

- Claude Code has become practical for non-programmers, turning a corner in accessibility and reliability
- The main value is doing tasks "with less attention" rather than faster—background processing means things actually get done
- Claude processed a 15-million-word Obsidian vault overnight, creating indexes and fixing issues across thousands of files
- Git version control is essential when letting AI make changes—commit after every change
- Clear, precise communication skills (like delegating to people) directly translate to effective LLM prompting
- The shift from knowledge management (organizing notes) to knowledge utilization (actually using them) is enabled by AI delegation
- Plan mode is essential for safety—it asks questions and avoids destructive actions
