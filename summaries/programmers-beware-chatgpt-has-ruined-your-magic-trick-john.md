# Programmers, beware: ChatGPT has ruined your magic trick

**Original source:** [Programmers, beware: ChatGPT has ruined your magic trick | John Naughton](https://www.theguardian.com/commentisfree/2023/apr/01/chatgpt-write-code-computer-programmer-software)
**Author:** John Naughton

## Summary

John Naughton argues that ChatGPT and similar generative AI tools represent a fundamental lowering of the barrier to programming, a skill that has historically been gated behind arcane knowledge and specialist languages. He frames the discussion through Steve Jobs' famous 1990 metaphor of computers as "bicycles for the mind" — tools that amplify inherent human abilities to spectacular magnitudes — and suggests that AI code generation is the latest and most powerful evolution of that idea.

The article highlights a practical demonstration by software engineer Steve Yegge, who prompted ChatGPT to write a working interactive Emacs Lisp function from a sloppy English description. The AI produced correct, decent-quality code in a single shot, illustrating how natural language can now substitute for programming expertise. Tech investor Paul Kedrosky is quoted describing such tools as "a missile aimed, however unintentionally, directly at software production itself," noting their ability to produce, debug, and accelerate software "quickly and almost costlessly."

Naughton observes that while many generalist journalists still dismissed ChatGPT as a trivial parlor trick, people within the technology industry were profoundly shaken by its implications. Since the networked world runs on software, making code generation accessible to non-programmers marks a significant democratization moment. The specialist knowledge that once gave programmers their authority — their "magic trick" — has been substantially undermined by tools that let anyone describe what they want in plain English and receive working code.

## Main Ideas

- ChatGPT's ability to generate working code from natural language descriptions fundamentally lowers the barrier to programming, making it accessible to non-specialists.
- Steve Jobs' 1990 "bicycle for the mind" metaphor applies powerfully to AI code generation as the latest amplification of human capability.
- A practical demonstration showed ChatGPT producing correct, quality Emacs Lisp code from a single sloppy English prompt.
- The technology industry sees generative AI as transformative, while many outside the industry still underestimate its significance.
- AI code generation tools are described as "a missile aimed directly at software production itself," with the potential to dramatically reduce the cost and time of creating software.
- The democratization of code creation challenges the traditional authority and mystique of professional programmers.
