# A Guide to Which AI to Use in the Agentic Era

**Original source:** [A Guide to Which AI to Use in the Agentic Era](https://www.oneusefulthing.org/p/a-guide-to-which-ai-to-use-in-the)
**Author:** Ethan Mollick

## Summary

The AI landscape has fundamentally shifted from chatbot interfaces to agentic systems where AI can autonomously complete multi-step tasks. Mollick introduces a three-layer framework for understanding AI: **Models** (the underlying AI brains like Claude Opus 4.6, GPT-5.2 Thinking, and Gemini 3 Pro that determine reasoning capability and accuracy), **Apps** (the products users interact with like ChatGPT, Claude.ai, and Gemini.google.com), and **Harnesses** (systems that give AI access to tools and enable autonomous action). This distinction matters because the same model can behave very differently depending on which harness it operates within—Claude Opus in a chat window is fundamentally different from Claude Opus inside Claude Code, which can autonomously write, test, and deploy software for hours.

The article provides a landscape review of current AI systems. The three frontier models are now roughly equivalent in capability but excel in different areas. When choosing an AI system, **model selection is critical for serious work**—free models are optimized for chat rather than accuracy, while paid options ($20/month minimum) provide access to more capable versions. The major apps (ChatGPT, Claude, Gemini) offer different feature bundles and harness capabilities. Claude and OpenAI have clear advantages in harness sophistication: both can write and execute code and conduct research, while Google's Gemini website lacks equivalent capabilities despite having a competitive model.

Beyond chatbots, specialized applications like Claude Code (for coders), Claude Cowork (for general knowledge work with local file access), Claude for Excel/PowerPoint (domain-specific harnesses), and NotebookLM (for research synthesis and knowledge management) represent where AI is heading: systems that don't just discuss work but autonomously execute it. Mollick emphasizes that this shift from chatbot to agent is the most significant change in AI usage since ChatGPT's launch, and learning to use these tools for actual work rather than demos is essential.

## Main Ideas

- **Three-layer architecture shapes AI capability**: Model choice, app interface, and harness sophistication all matter equally—the same model performs differently in different contexts
- **Frontier models are converging but harnesses diverge**: GPT-5.2, Claude Opus 4.6, and Gemini 3 Pro are close in raw capability; competitive advantage now comes from tools and autonomous access
- **Model selection is underemphasized and critical**: Users rarely know they can select which version of a model to use (e.g., GPT-5.2 Thinking vs. GPT-5.2 mini), resulting in dramatically worse performance
- **Specialized harnesses unlock new categories of work**: Claude Code and Claude Cowork enable autonomous execution of complex projects (coding, data analysis, document processing) without manual intervention
- **The shift to agentic AI is fundamental**: AI that autonomously completes tasks is more transformative than chatbot interfaces, with cascading implications for productivity and job functions
- **Harness sophistication varies significantly across platforms**: Claude and OpenAI lead in tool access and research capability; Google trails despite competitive model quality
- **Practical recommendation**: Start with a $20/month subscription to one of the three major systems, select the advanced model, and use specialized tools (NotebookLM, Claude Code) for specific workflows
