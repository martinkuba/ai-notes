# It's harder to read code than to write it (especially when AI writes it)

**Original source:** [It's harder to read code than to write it (especially when AI writes it)](https://www.coderabbit.ai/blog/its-harder-to-read-code-than-to-write-it-especially-when-ai-writes-it)
**Author:** Aleks Volochnev

## Summary

This article from CodeRabbit explores the well-known asymmetry between writing and reading code, and argues that AI-generated code amplifies this challenge significantly. The piece draws on Brian Kernighan's famous observation that debugging is twice as hard as writing code, implying that if you write code at the limit of your cleverness, you won't be smart enough to debug it. The article extends this principle to the age of AI-assisted coding: when AI writes the code, the human developer may not have the mental model of the code's construction, making it even harder to read, review, and debug.

The core concern is that as AI coding tools become more prevalent, the volume of code that needs to be reviewed by humans is increasing rapidly, while the cognitive burden of understanding AI-generated code is higher than for human-written code. Developers lack the contextual understanding that comes from having written the code themselves, making code review a more critical and more difficult task. This creates a growing need for better tooling to assist with code review and comprehension in AI-heavy workflows.

## Main Ideas

- Reading and understanding code is inherently harder than writing it, a principle long recognized in software engineering.
- AI-generated code exacerbates this asymmetry because developers lack the mental model that comes from having written the code themselves.
- As AI writes more code, the volume requiring human review increases while comprehension difficulty also rises.
- Better code review tooling is essential to manage the growing challenge of reviewing AI-generated code.
- The debugging complexity problem identified by Kernighan becomes more acute when the original "author" is an AI system.

## Key Quotes

- "Debugging is twice as hard as writing the code in the first place. Therefore, if you write the code as cleverly as possible, you are, by definition, not smart enough to debug it." -- Brian Kernighan
