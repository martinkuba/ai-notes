# How I Use Obsidian + Claude Code to Run My Life

**Original source:** [How I Use Obsidian + Claude Code to Run My Life](https://www.youtube.com/watch?v=6MBq1paspVU&list=WL&index=6)
**Author:** Greg Isenberg

## Summary

Greg Isenberg interviews Vin (Internet Vin) about how he uses Obsidian paired with Claude Code as a thinking partner and personal operating system. Vin explains that Claude Code is a command-line agent that can control your computer through natural language, and the key insight is that you can reference files to give it persistent context rather than re-explaining projects in every session. Obsidian is a markdown-based note-taking tool whose distinguishing feature is bidirectional linking between files, creating a graph of interconnected ideas. With the Obsidian CLI, Claude Code gains access not just to individual files but to the relationship graph between them, enabling it to surface patterns across your entire vault that you would never see on your own.

Vin demonstrates a suite of custom terminal commands he built for his workflow: `/context` preloads his full life context (projects, preferences, daily notes); `/today` creates a prioritized daily plan from calendar, tasks, messages, and recent notes; `/ghost` answers questions in his own voice by building a profile from the vault; `/challenge` pressure-tests his beliefs using his own history; `/emerge` surfaces ideas the vault implies but never states; `/drift` compares stated intentions against actual behavior over 30-60 days; `/ideas` runs a comprehensive idea generation report across all domains; `/trace` tracks how a specific idea has evolved through the vault over time; and `/connect` bridges two unrelated domains using the vault's link graph. The ideas demo is particularly striking -- after reading dozens of files across projects, daily notes, and context files for several minutes, it produces actionable suggestions for tools to build, people to talk to, subjects to investigate, and things to publish, all grounded in Vin's actual notes and patterns.

The conversation explores deeper themes: Vin maintains a strict rule that only he writes into the vault (the AI reads but never writes to it) to ensure patterns it finds are genuinely his own. He discusses privacy concerns of giving agents deep access to personal information, the parallel to therapy (the AI connects dots like a coach or therapist), and the fundamental shift in the human-computer relationship. Isenberg concludes that markdown files are the "oxygen" of LLMs and that cultivating a writing/reflection habit is now a competitive advantage because it produces the context that makes AI delegation dramatically more effective.

## Main Ideas

- Claude Code paired with Obsidian creates a "thinking partner" that can surface patterns, connections, and latent ideas across your entire knowledge base that you would never notice on your own.
- The key problem with current AI tools is context: built-in memory features are uncontrollable, but file-based context (passing specific markdown files) gives you full control over what the AI knows.
- Custom commands (slash commands in the terminal) turn complex multi-file analysis workflows into repeatable one-liners, from daily planning to idea generation to belief challenging.
- Maintaining a strict separation -- the human writes all vault content, the AI only reads it -- ensures that pattern detection reflects genuine human thinking rather than AI-generated content.
- The quality of AI output is entirely determined by the quality of context you provide; continuously maintaining an up-to-date vault is the new form of "managing" an AI agent.
- Writing and reflection are now competitive advantages because they produce the structured context that enables effective AI delegation and deeper idea generation.
- The Obsidian + Claude Code combination functions like a therapist or coach -- connecting dots, surfacing what you are avoiding, and naming patterns you have been circling around.

## Key Quotes

- "The quality of information that the agent has entirely determines what it can do for you. If it doesn't know a lot about you, it's not going to be able to do a lot for you."
- "I create a rule for myself which is like a strict separation... I only want it to write things on the side, and then I will take that and write what I think should be included."
- "People think tokens are the oxygen. But they're not. The markdown files are the memories."
